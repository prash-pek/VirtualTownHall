Decided by Prash 2026-10-15 (product vision thread). Doc: /mnt/project-files/townhall/vision/product-vision.md.

- Voters are the customer; candidates are participants. This flips PRD §1 ("candidates are the primary customers").
- Phase 1 = get a voter through their ballot from cited sources: ballot, optional values evaluation/Alignment, item walk-through with the per-item discussion (every candidate or YES/NO answers each question from our sources, one call for all sides), summary. Per-item discussion is UNHELD.
- Phase 2 = candidate platform: claim flow, first-person voice, uploads/admin panel, Reflection score computation, candidate analytics, TRD phase 6. Later horizon: follow winners into office.
- Phase 1 shows a "Are you this candidate? Let us know" contact, no claim flow.
- Strict sourcing: if sources don't cover a question, say so. A future setting may allow labelled reasoning; strict is default.
- Data: resume collection after phase 3 publishing works, Portland metro first, only fields phase 1 shows.

**Why:** candidates come where voters are; trust in neutrality must come before campaigning; credits.
**How to apply:** don't build phase 2 features until Prash asks. See [[townhall-decisions]], [[oregon-pipeline-paused]].

Endorsements (Prash, 2026-10-15): collapsed "Endorsed by" dropdown per candidate and measure side; fixed list of well-known outlets across the spectrum (WW, Mercury, Oregonian to start) plus org/official endorsers incl. voters' pamphlet; no voter outlet picking; NOT part of Alignment (shown, never scored), visible in the per-item discussion; build alongside the discussion.
